# DietTrack

A Django health-tracking system with BMI profiles, food tips, exercise recommendations, and budget-based meal suggestions.

## Features
- User health profiles and BMI status
- Food recommendations with estimated prices
- Daily or monthly food budgets
- Exercise recommendations by intensity and location
